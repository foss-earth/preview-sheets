# Preview-sheet composition

`@foss-earth/preview-sheets/composition` exports `createPreviewSheetsCompositionOwner`. The root also exports the pure structural factory. `@foss-earth/preview-sheets/composition-node` exports `createNodePreviewSheetsCompositionOwner`, adding required face/cell equivalence verification. Both fit injected scene composition ports without importing or depending on Scenes, its application, or a renderer.

Each child entry supplies its final media base, key and raw extension records. Public sheet/place validators resolve records and reject every warning about discarded optional metadata. Identical immutable sheet records deduplicate by output identity; differing revision, URL, dimensions, format or byte length fails. Explicit `aliases[childKey][originalSheetId] = outputSheetId` resolves conflicts and must be reversible within each child. Unknown child/ID aliases fail. Cell x/y and original six face records remain intact. Output contains publishable sheet records and places, never a transient runtime `sheet`. `files` enumerates the validated immutable sheet URLs and byte declarations for the host's independently pinned media check.

The Node hook accepts `verificationLimits` and `minPsnrDb`; defaults retain 28 dB RGB equivalence. The preparation verifier accepts the same limits as an optional fourth argument. It caps assets, sheets, representations, file reads, per-file/cumulative input bytes, decoded pixels and pixel work. Before each decode it reserves all retained sheet RGBA bytes plus the complete Images codec working reservation, including the temporary face's output. Comparison allocates no cropped image. Returned `stats` reports charged input/work/pixels, retained sheets and peak codec working bytes. Metadata and PNG inflation are bounded by the public Images codec contract. These are known-buffer accounting and conservative workspace reservations, not process/GPU/RSS or GC measurements.

Cancellation is checked before/after host reads and between sheets, faces and comparison rows. Synchronous native inflate/JPEG calls cannot be interrupted by a signal arriving on the same thread; an owned worker/process is required for an interruptible wall deadline. Resource limits and cancellation stop required verification; missing/corrupt/mismatching content produces required diagnostics and never successful fallback acceptance. Runtime optional fallback behavior and source packing remain unchanged.

Tiny authored fixtures qualify this API. No Campus corpus encoding, media publication, provider request, browser/renderer initialization or remote admission is implied.
